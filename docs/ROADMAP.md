# Crossbow 迭代路线图

> 基于 2026-10-04 M0（tag `m0.1`）交付后的规划，按「日常使用价值优先」排序。
> 每个里程碑完成即打 tag；范围可在实际使用反馈中调整。
>
> 平台：macOS（现役）→ Windows（M1.5）→ iOS（M2）。TUN 暂缓，
> 重启触发条件：出现「某应用流量不走代理」的真实困扰（见 DESIGN.md）。

## M1 · macOS 完整版（约 4–6 周）

### M1.0 正式打包与自更新（~1 周）✅ 2026-10-04
*目标：摆脱终端，像正式产品一样安装使用。*
- ✅ `tauri build` 产出 .app（62MB，mihomo sidecar 随包分发），打包版启动冒烟通过
- ✅ 内核缺失自动下载（gh-proxy 镜像优先，锁定 v1.19.32，大小校验）
- ✅ updater 基础设施：签名密钥对、createUpdaterArtifacts、应用内「检查更新」（端点待发布渠道）
- ⏭ 待办：bundle identifier 从 com.crossbow.app 迁移（.app 后缀冲突告警，需同步迁移数据目录）
- ⏭ 待办：dmg 打包（无公证环境的 bundle_dmg.sh 问题）与发布渠道（GitHub Releases + latest.json）
- 验收：双击 .app 日用一整天，无终端依赖 ← *请用户验收*

### M1.1 订阅生命周期完善（~1 周）
*目标：订阅不再是「导入一次就不管」。*
- 自动更新调度（interval 模型已有）：后台定时刷新 + 失败保留旧配置 + 重试退避
- 订阅卡片显示下次更新时间/最近失败原因
- 更新后正在运行则热重启（已有）
- 验收：修改远端订阅内容，到点自动生效；远端挂掉不影响现有使用

### M1.2 可观测性与诊断向导（~1.5 周）
*目标：把「为什么不通」从用户提问变成一键自检。M0 实际使用已暴露此类困惑。*
- 网络诊断向导：系统代理生效性 → 内核状态 → 节点连通性 → DNS 泄漏 → 规则命中，逐步可点击修复
- 首页「当前出口」实装（读内核 API）
- 连接页完整交互：单连接断开、按进程聚合、进程图标
- 首页状态灯语义化（直连/系统代理/异常 三态醒目）
- 验收：模拟断网场景，向导能定位到具体环节并给出可用修复动作

### M1.3 配置能力与进阶（~1.5 周）
- JS 脚本覆写（嵌入 JS runtime）+ merge/JS 覆写编辑器 + 示例覆写市场
- sing-box 引擎切换（CoreAdapter 已抽象，补配置渲染 JSON target + 下载管理）
- 轻量模式：关窗只留内核（launchd user agent 托管），托盘常驻
- 验收：用示例覆写完成一次「去除失效节点」的实战改造；轻量模式下内存 < 80MB

### M1.4 备份与迁移（~1 周）
- WebDAV 备份/恢复（凭据入 Keychain）
- 本地快照恢复 UI（已有 5 份自动快照）
- 导出/导入完整配置包（为跨设备迁移铺路）
- 验收：换机场景 10 分钟内恢复全部配置

## M1.5 · Windows 版（约 3–4 周）

- NSIS 安装包 + Authenticode 签名 + updater
- 系统代理：注册表 + WinINet 刷新（sysproxy trait 已预留）
- 凭据管理器、深链接、自启
- 双平台 QA（高分屏 DPI、杀软误报抽测）
- CI 已就绪（Windows 矩阵从 M0 起持续守护）
- 验收：与 macOS 功能对齐（不含 TUN）

## M2 · iOS 版（约 4–6 周，需先决策开发者账号）

- SwiftUI App + PacketTunnelProvider（libbox）
- crossbow-core 经 UniFFI 静态链接；App Group 配置共享
- iCloud 双端同步（Profile/节点选择/设置）
- TestFlight 公测 → App Store
- 前置决策：Apple Developer 账号（$99/年）；VPN 类上架审核材料

## M3 · 打磨池（持续吸收真实使用反馈）

- 规则命中统计与可视化
- 请求日志复制为 cURL
- DNS 泄漏检测面板
- 内核控制器收紧为 uds/pipe（安全加固，DESIGN §3.4）
- Windows OneDrive 同步桥评估
- TUN 重启评估（触发条件见上）

## 横切关注点（每个里程碑都做）

- 真实使用反馈清单：日常使用中每一条不便记录到 issue/讨论，纳入下个 M 排序
- GeoIP 镜像列表维护（`GEO_FILES`，纯数据可随时改）
- 双平台 CI 绿灯；跨平台不写破坏性平台代码
- 升级前配置自动快照；schema 迁移带测试

## 已知债务（择机偿还）

- 连接页 5000+ 连接的极端性能验证
- `free_port()` 端口竞态（S2 注释中已记）
- 系统代理 bypass 列表可配置化
