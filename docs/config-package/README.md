# 配置包与换机恢复（v2，#607）

在桌面“配置 → 配置来源 → 备份与迁移”导出或导入。包是**未加密 JSON**，可能包含订阅/规则 URL token、节点凭据、覆写脚本和个人策略；需私密保存。macOS/Linux 新文件为 0600；Windows 访问权限依保存目录 ACL。没有加密或云同步承诺。

## 包含与排除

v2 携带配置来源及其已缓存内容、覆写与执行顺序/绑定/启停、当前配置选择、进程规则及列表顺序、独立规则集元数据/启停/更新间隔和经过本地格式验证的缓存。

规则集缓存始终随元数据打包，不支持本次单独选择“只带 URL 不带缓存”。支持现有 domain/ipcidr/classical 文本子集，不含 MRS/SRS。单规则集遵守原有 2 MiB/50000 条上限，整包 8 MiB；过大则拒绝，不静默丢弃缓存。规则集错误及旧更新时间不迁移；导入确认时将缓存时间置为本机当前时间，避免旧时间戳导致立即下载。

不携带应用级 DNS、内核选择/端口、系统代理快照、TUN/服务接管状态、权限/PID、外观、SSID 场景、日志或诊断。本版没有 SSID 导出选项；任何源包中的机器状态不用于开启新机器接管。配置/覆写**原文中的** DNS 或脚本仍是用户选择迁移的内容，需信任来源。

**域名/IP 用户规则不在 v2 迁移范围**（v2 定稿时该功能尚未进入 main）：导出不携带，导入也不会覆盖或删除本机用户规则。需要跨机迁移用户规则时，请等后续包版本，issue #605 的规则仍只在本机生效。

## 版本与合并

- 写 v2、读 v1/v2；未来版本或未来存储 schema 明确拒绝。v1 示例保留为兼容夹具，它不覆盖或清空本机进程规则/规则集。
- 按稳定 ID 替换，不按名字重写 ID。包外条目保留；进程/规则集顺序为本机未被替换条目在前、包内顺序在后。相同 ID 的条目用包内版本替换。
- 不同 ID 的同名 Profile/覆写保留各自身份，预览显示数量；进程名或规则集名称重复会形成含糊优先级，预览提示冲突并禁止确认，后端亦拒绝。
- 覆写绑定、当前选择及重复 ID 必须有效；共享覆写影响包外配置时沿用既有冲突保护。
- 策略目标按**名称**原样保留，绝不降级为 DIRECT。预览只作原始配置静态检查，未确认目标给出数量；确认时复用实际覆写后的渲染结果检查，缺失或当前内核不支持则整批回滚。进程规则仅接受有效策略组/出站目标；规则集沿用其有效目标范围。

## 网络与事务边界

预览不下载订阅/规则，不执行覆写脚本；只返回脱敏计数和随机预览句柄。确认后才会运行配置校验及必要的内核重载；保留的更新计划以后可能访问源 URL。缓存无需立即下载即可使用；启用规则集按原周期（300–604800 秒）刷新。本版没有单独的永久离线缓存模式，停用规则集同时停止注入和自动刷新。

预览指纹包括配置/覆写/当前选择、进程规则、规则集、DNS 和内核设置。取消无写入；过期预览拒绝；内核校验、应用或保存失败沿用已有事务回滚。快照恢复同样包含这两类个人策略，同时保留本机设置。

## 复现与验收

[v1 示例](example.json) / [v2 示例](example-v2.json) 均使用保留域名；订阅更新关闭，v2 的规则集默认停用（缓存仍携带）。建议在独立数据目录验证：先取消、再确认，重启后核对来源、绑定、进程规则和缓存；重复导入只替换同 ID 项。再测试名称冲突、目标缺失、坏缓存、未来版本及保存失败，确认原库和接管状态不变。

本地 Rust 覆盖新旧包、合并/替换、规则格式与目标、磁盘往返、失败回滚及预览指纹；生产组件模拟覆盖范围说明、冲突禁用、取消、失败与最小窗口。隔离真实 mihomo 验证了从包恢复到新库后规则缓存生效，停用后直连回显恢复；进程规则只验证恢复内容与内核接受，未模拟所有进程归属。

真实两台机器、安装版文件对话框、运行中的用户配置重载/失败恢复和跨平台换机仍待验。旧版原生记录不作本版全部验收证据。
