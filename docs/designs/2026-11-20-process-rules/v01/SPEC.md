# 进程规则界面 · v01

状态：已实现，待用户与 PR 评审。关联 #570 / PR #582。日期 2026-11-20。

## 设计

沿用 Crossbow 既有颜色、字号和统一控件。参考私人设计知识库的新极简网格原则与 Emil 的控件细节，明确列对齐、适度分隔和渐进展示，避免操作孤立在内容之外。

| Before | After | Why |
| --- | --- | --- |
| 添加按钮单独一行、信息没有列头 | 规则计数与添加操作组成工具栏；进程/策略/操作三列 | 明确阅读与操作顺序 |
| 目标原始 DIRECT/REJECT、操作距离很远 | 本地化直连/拦截，箭头表达映射，限制整体阅读宽度 | 便于理解分流关系 |
| 行内临时输入挤压列表 | 统一 Dialog 中编辑，字段标签完整 | 保持列表稳定，兼容小窗口和键盘 |
| 错误时关闭输入 | 失败保留草稿，保存期间防重入 | 可直接修正和重试 |

共享组件：Button、Select、Input、Dialog、Icon、Notification。主题使用现有 token，无新增外部字体/图标包。

## 可编辑源稿与预览

`source.zip` 保存生产组件、样式和可重跑的验证脚本。运行：在对应 PR checkout 安装依赖后 `CB_PROCESS_EVIDENCE=/tmp/process-preview node scripts/dev/verify-process-rules.mjs`。

预览为实际 React 组件 + 脱敏 IPC，Chromium/macOS arm64；浅色中文1120×720、深色中文880×560、深色英文880×560（长进程名编辑）、失败保留输入及空状态。改前取自原 PR 组件，合并 main 后、重设计前。

模拟验证保存失败、重试、移除、空状态、窗口溢出及连接行一键跳转预填；不能证明真实内核分流。真实进程命中、Windows 名称匹配与 sing-box 完整启动仍待原生验收。用户最初发的网络场景截图属于 #580，本设计不涉及该功能。
