# Crossbow 官网设计提案

关联 Issue #174。正式官网尚未替换，当前推荐查看 **v03 白色一屏方案**。

| 版本 | 状态 | 设计 |
| --- | --- | --- |
| [v03](v03/index.html) | 待评审 | 白色一屏首页，原生连接路径；功能、指南、下载独立页面 |
| [v02](v02/index.html) | 已替代 | 绿色文字主导长页面；用户要求改为白色与独立页面 |
| [v01](v01/index.html) | 未采用 | 长页面及界面片段；用户不希望截图式图片 |

每版保留源稿、规格、实际截图和 manifest。以各版 SPEC.md 为准。

本地预览：在任一版本目录运行 `python3 -m http.server 5192 --bind 127.0.0.1`，然后打开 http://127.0.0.1:5192/ 。无需安装依赖。v03 的 `generate.py` 可重新生成其静态 HTML。
