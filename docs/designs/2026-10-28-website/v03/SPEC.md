# Crossbow 官网设计 · v03

日期：2026-10-28。Issue #174。提案，未部署。

## 最新明确要求

用户不喜欢 v02 的颜色，要求接近应用白色主题；主页内容精简为一屏，中间采用设备 → 规则分流 → 网络的介绍；从顶部导航进入独立功能页等细节，不再做长滚动首页。继续禁止截图式产品图片。

## 本版设计

白色背景 #fff、文字 #242b37、次级文字 #596777、强调色 #455ab5、主按钮 #293345，沿用应用白色主题的语义角色；保留原 Crossbow 品牌标志。参考 apple-design 的可预期层级与反馈、emil-design-eng 的细节与动效约束，并以 landing-page-design 的清晰用途/主动作组织文案。用户指定的布局、配色与无截图要求优先，不照搬 skill 随机方向。

主页只放产品一句话、用途说明、中央原生路径图、下载与一行辅助说明。路径每次一个数据包，840 ms 快速前进，完成后约 2.56 秒等待；图标和文字不动，后台/手动暂停与减少动态效果都有处理。路径不是实时连接状态。

独立页面：index.html 首页、features.html 功能、guide.html 使用指南及 FAQ、download.html 平台下载、privacy.html 本地原型隐私说明、404.html。顶部导航均为真实页面链接，选中页明确标记；移动端折叠菜单。功能细节不在主页堆积。

承接 v01/v02 核对的当前 main 功能：订阅与本地配置、自动更新、Merge/Script、mihomo/sing-box、节点地区筛选/搜索/可用过滤/排序与测试、自动或手动选择、独立系统代理/TUN、托盘速率、日志/连接/诊断/四站点检测。iOS 只标注开发验证中，下载跳转官方 Releases，不写死可能变化的版本号。
