安装客户端

在官方 GitHub Releases 中选择与你设备匹配的安装包。当前公开提供 macOS Apple Silicon 和 Windows x64 版本。

下载后按安装说明操作，校验文件可参考同一版本附带的 SHA256SUMS。

选择下载版本 →

导入你的配置

打开「配置」，添加订阅链接或导入本地文件，再选中要使用的配置来源。订阅可以按周期更新；需要个性化修改时，再配置 Merge 或 Script 覆写。

Crossbow 不提供节点或订阅服务。配置中可能包含凭据，请妥善保存。

选择节点，开始连接

在节点页进行延迟测试，选择节点或自动选择策略，再开启适合自己的接管方式。

系统代理
适用于遵循系统代理设置的应用。
TUN 模式
通过虚拟网卡接管流量，首次使用需完成相应授权或服务配置。

两种方式可以独立控制或同时开启。请选择自己的常用应用验证实际访问情况。

有问题，先看链路。

先确认配置和节点有效，再查看连接、日志和诊断。可以结合站点连通性测试，区分节点响应、目标站点与应用代理设置的问题。

如果同时运行其他代理或 VPN，请避免重复接管或路由冲突。反馈问题时附上版本、操作系统和脱敏后的诊断内容。

常见问题

测速成功，就一定可以访问吗？＋

不一定。延迟测试、站点响应与浏览器实际访问是不同检查。结合连接列表、日志和实际应用表现判断。

系统代理与 TUN 能同时打开吗？＋

可以，两个开关独立控制，共用本应用内核。使用其他代理或 VPN 时应避免路由冲突。

两种内核的配置通用吗？＋

不一定。协议、规则和配置兼容性以所选 mihomo 或 sing-box 内核为准。

iOS 可以下载了吗？＋

iOS 仍在开发验证，目前没有公开分发入口。公开下载平台以官方 Release 资产为准。

如何检查更新？＋

在应用的设置页检查更新，或前往官方 GitHub Releases 查看版本说明与安装包。

提交问题时，哪些信息不能公开？＋

不要公开订阅链接、token、节点密码等凭据。只提供版本、系统、复现步骤和脱敏后的日志或诊断内容。
