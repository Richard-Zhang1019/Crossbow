节点与分流接管方式配置与内核监测与诊断

选节点，不靠猜。

先找到合适的节点，再决定怎么连接。

搜索、筛选与排序

搜索节点名称或协议，按地区收拢节点；筛选可用结果，按延迟排序。

测速状态原位展示

支持单节点与整组测试。测速中的状态、返回的延迟和超时结果都留在原位。

自动选择，也能手动切换

根据配置使用自动选择，或手动指定节点；直连、规则与全局模式按场景切换。

怎么接管，由你决定。

系统代理和 TUN 各有用途，也可以同时开启。

系统代理

让遵循系统代理设置的应用，经由 Crossbow 连接。适合浏览器等常用应用。

TUN 模式

用虚拟网卡接管系统流量，覆盖不读取系统代理的应用。首次使用需完成对应平台的授权或服务配置。

菜单栏与托盘

实时查看上下行速率，快速切换节点与接管方式，不必每次返回主窗口。

配置，按自己的习惯。

原始配置与个性化修改，分别管理。

mihomosing-box

订阅与本地文件

导入已有订阅链接或本地配置，管理多个配置来源，并设置订阅更新周期。

Merge 与 Script 覆写

合并配置片段，或通过脚本整理配置。将自己的修改绑定到需要的配置来源。

双内核选择

按配置需要选择 mihomo 或 sing-box。协议和规则兼容性以所选内核为准，切换后仍需验证配置。

连接有迹，问题可查。

从连接去向，到日志和诊断，逐层寻找线索。

连接与流量

查看目标站点、命中规则、出口与流量，了解连接实际走向。

内核日志与网络诊断

查看运行日志，检查内核、控制器、端口、代理和 DNS 等环节。反馈问题时可复制脱敏详情。

站点连通性测试

检测 YouTube、X、Google、GitHub 的站点响应。测试结果是排查线索，实际使用仍需由常用应用验证。
