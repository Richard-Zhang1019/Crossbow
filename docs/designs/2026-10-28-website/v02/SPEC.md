# Crossbow 官网设计 · v02

日期 2026-10-28 · Issue #174 · 设计提案，未部署。

## 用户纠正与范围

v01 的截图式功能面板被用户否定。v02 从头重做：不使用任何产品截图、仿截图图片、设备壳、仿应用面板；仅沿用品牌标志和事实依据，v01 保留供追溯。

## 设计方向

重新使用 design-taste-frontend、landing-page-design、emil-design-eng。方向 Type and nothing else，seed 1477126414；首屏采用 Waterline headline，纸白与森林绿在中线相接，标题跨越分界，支持文案与下载动作落在下沿。后续 Giant command list 以「选节点 / 定规则 / 查问题」组织产品能力，不再堆砌界面卡片。

抽取配色为 Tobacco and olive，与技术产品/连接状态语义不符，因此映射为纸白、墨绿与浅鼠尾草；保留单色场比例。抽取的英文标牌双字体不适合以中文为主的正文，使用 landing-page-design 允许的 Manrope 配系统中文后备。用户“不希望截图式图片”的明确要求优先于 skill 的产品 UI 图片数量要求；页面不增加为凑数量的图片。

概念：Crossbow 中的规则分流成为阅读和交互的线索。网站自身的语义路径图说明「应用 → Crossbow → 代理 / 直连」，不是应用界面复刻。规则/全局/直连按钮改变路径说明；动画只是示意，不触发网络操作。单个信号 0.84 秒移动，剩余约 2.56 秒等待；减少动态效果与暂停均有静态方案。

## 内容依据

基于 main c4ab8cd 的 ipc.ts、Proxies、Profiles、OverridePanel、SiteConnectivity、Connections、Logs、Diagnostics 和 lib.rs；下载通过官方 Releases，不硬编码版本。README 版本/平台文案过期，不沿用其 Windows TUN 尚未开放与 iOS 骨架表述。iOS 根据 apps/ios/README.md 标为开发验证中，不设置公开下载按钮。

网页说明包括订阅/本地配置/定时更新、节点筛选/排序/逐项整组测速/自动选择、双内核、独立代理/TUN、运行监测/诊断/站点测试、托盘操作与速率、更新入口。所有功能演示均不暗示性能或可用性保证，不虚构节点服务和用户评价。

## 验收

桌面、平板、手机；双层标题在分界处重合且无辅助技术重复朗读；所有标题最多两行；模式切换、FAQ、移动菜单、下载锚点、暂停与 reduced motion；无图片请求丢失/无脚本错误/无水平溢出。预览 noindex，正式 SEO 信息在确认上线时处理。

## 用户反馈

用户不喜欢本版配色，希望白色主题、简短的一屏主页，中央用设备/规则/网络路径介绍产品；功能与指南由顶部导航进入独立页面。后续见 v03，本版留存。
