Crossbow 包含节点或订阅吗？＋

不包含。Crossbow 是开源代理客户端，需要自行准备合法、可用的订阅或配置。下载客户端不等于购买节点服务。

支持哪些平台？＋

官方 Release 提供 macOS Apple Silicon 与 Windows x64 安装包。iOS 正在开发验证，尚无公开分发入口；平台支持以实际发布资产为准。

系统代理与 TUN 可以同时开启吗？＋

可以，Crossbow 提供独立开关。系统代理依赖应用读取代理设置，TUN 使用虚拟网卡接管流量；使用其他代理或 VPN 时，应避免重复接管和路由冲突。

测速成功就代表一定能访问吗？＋

不一定。延迟测试、站点响应和浏览器实际访问是不同检查，可以结合连接列表、日志和诊断结果排查，再用常用应用验证。

双内核的配置都通用吗？＋

不一定。桌面支持 mihomo 与 sing-box，协议、规则和配置兼容性以所选内核为准；切换内核后仍需验证配置。

在哪里更新，如何反馈问题？＋

在应用设置里检查更新，或访问官方 GitHub Releases。反馈问题请附版本、系统与脱敏诊断信息，不公开订阅 token 和节点密码。
