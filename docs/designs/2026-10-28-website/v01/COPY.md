# 官网文案 v01

## 产品定位与首屏
把连接的去向，
看得清清楚楚。
Crossbow 是 macOS 与 Windows 的开源代理客户端。把订阅、节点、系统代理与 TUN 放在一起，也把每条连接的状态留在眼前。
主动作：下载桌面版。事实：macOS Apple Silicon / Windows x64，GPL 3.0 开源。

## 节点
选对节点，不靠猜。
搜索名称或协议，按地区收拢节点，用延迟排序找到可用的选择。逐项或整组测试，结果留在原位。

## 接管方式
你的连接，你来决定。
只接管遵循系统代理的应用，或用 TUN 接管系统流量。两种方式独立控制，也可以同时开启。

## 运行监测
连接有迹可循，问题有处可查。
查看正在建立的连接、命中的规则与流量。结合日志、网络诊断和站点检测，逐层缩小问题范围。

## 配置
保留你的配置，组织你的规则。
导入订阅或本地文件，设置更新周期。用 Merge 和 Script 覆写管理自己的修改；按配置需要选择 mihomo 或 sing-box。

## 上手
从一份配置开始。
安装桌面版。导入已有订阅链接或本地配置。选择节点，开启适合自己的接管方式。

## FAQ
Crossbow 提供节点或订阅吗？不提供；需要自行准备合法可用的订阅或配置。
系统代理和 TUN 有什么区别？前者依赖应用读取系统代理；后者使用虚拟网卡接管流量，具体行为取决于规则、系统权限和网络环境。
两种模式可以同时开吗？可以，Crossbow 提供独立开关；使用其他代理或 VPN 时应避免流量与路由冲突。
支持哪些平台？公开 Release 提供 macOS Apple Silicon 与 Windows x64 安装包；iOS 正在开发验证，尚无公开下载入口。
测速成功就代表所有网站都能访问吗？不一定。延迟测试和站点响应反映不同链路，站点检测不能替代浏览器与真实使用验证。
支持哪些内核和配置？桌面支持 mihomo 与 sing-box；协议、配置与规则兼容性以所选内核为准，内核切换不代表任意配置都兼容。
如何更新和反馈问题？在设置里检查更新或访问官方 Releases；提交 Issue 时附版本、系统和脱敏诊断信息，不提交订阅 token 或密码。
