# 节点卡片随可用高度分页

状态为已实现、待评审。关联 [#410](https://github.com/Richard-Zhang1019/Crossbow/issues/410)。

筛选栏到站点连通性之间的实际高度决定每页行数。用三行卡片的最低高度、两道行间距和必要的分页器高度判断是否放得下第三行。空间较少时排两行，允许卡片在 68–100 CSS px 之间均匀伸缩。末页不足整页行数时使用紧凑卡片，单页无需分页时也不预留分页器空间。

分页器右对齐，位于最后一行下方 8px。卡片到达上限后，剩余空间留在分页器与底部站点连通性之间。矮窗收紧页头与站点连通性间距，省略该区的辅助说明。结果详情扩展时允许工作区滚动。

生产实现位于桌面节点页和共享 FitItems。预览直接加载生产组件并提供 13 个脱敏示例节点。仓库根目录安装依赖后运行：

```sh
apps/desktop/node_modules/.bin/vite --config docs/designs/2026-11-10-adaptive-node-pagination/v01/vite.config.mts
```
