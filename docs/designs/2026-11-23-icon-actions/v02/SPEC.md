# 随文操作图标 v02

2026-11-23，#643 / PR #646。用户纠正 v01：复制与修改应像文本后的 inline 操作，复制成功原位显示绿色小勾。此版替代 v01 的卡片按钮式 hover。

当前方案：名称、地址、字段文字后的编辑/复制图标为主题强调色（浅色蓝、深色沿用 Crossbow 强调色），16px 图形、24px 点击区。常态与 hover 都无按钮边框/底板；hover 仅改变图标颜色，键盘保留焦点提示。复制成功保留相同尺寸/位置，变成 cb-ok 绿色小勾；失败不假成功，超时恢复复制图标。

配置名称缩小间距；LAN 复制从行末移入地址后，网卡名成为后续元信息；连接详情由三列改成标签/值两列，复制图标直接跟在每个字段值之后，长内容仍允许换行。列表编辑统一轻量外观；工具栏刷新可保留紧凑按钮形态。行为、通知和权限不变。
