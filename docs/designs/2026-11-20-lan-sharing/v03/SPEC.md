# 局域网共享访问指引 v03

关联 #568 / PR #583。状态为已实现，待评审。

用户反馈 [v02](../v02/SPEC.md) 把开关与接入步骤拆成了多个同级设置行。本版将「允许局域网连接」作为一个可展开的设置项。

- 顶部沿用设置页的标题、警示文字和开关。整项以设置页的横线收尾。
- 开启时，操作说明、网卡地址和辅助操作在开关下方缩进，细竖线标记从属关系。背景沿用页面底色。
- 地址与网卡名相邻，复制按钮跟随对应地址。刷新与故障提示位于接入区底部。
- 关闭时收起接入区，公共 Wi‑Fi 提示仍可见。

## 预览与复跑

运行 `CB_LAN_EVIDENCE=/tmp/crossbow-lan node scripts/dev/verify-lan.mjs`。浏览器以脱敏 IPC 数据渲染生产组件。预览为浅色中文 1120×734 和深色英文 880×560，覆盖复制、多网卡、端口更新、读取重试和开关成功与失败。手机同 Wi‑Fi 接入及关闭后停用属于原生验收。
