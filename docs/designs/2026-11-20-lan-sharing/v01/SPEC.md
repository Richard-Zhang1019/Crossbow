# 局域网共享访问指引

关联 #568。状态为已实现，待评审及实机验收。入口位于「设置 → 网络与内核 → 连接设置 → 允许局域网连接」。

设置行持续展示公共 Wi‑Fi 风险，和现有开关关联。开启后在行下显示接入说明。每条记录包含网卡名、IPv4 地址和当前混合监听端口，使用系统剪贴板复制 `IP:端口`。窗口重新聚焦或点击刷新可更新地址。读取中、无可用地址和读取失败分别提示，失败可重试。

面板沿用设置页对齐线、明暗主题与共享按钮。开关状态由后台配置回读确认。关闭后收起面板；切换失败时依据回读保留实际配置。已有代理监听和持久化逻辑继续负责接口绑定、重启与回滚。手机使用前需启动内核，且设备须能访问电脑的混合端口。
