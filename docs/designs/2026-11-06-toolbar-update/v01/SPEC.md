# 顶栏更新入口 v01

状态：已实现，待评审。关联 issue：[#337](https://github.com/Richard-Zhang1019/Crossbow/issues/337)。

概览不再预留更新横条。发现新版本时，在配置选择器前加入一个与顶栏按钮等高的更新入口。入口在页面切换后仍可使用，无更新状态或平台不支持应用内更新时隐藏。

| 窗口宽度 | 按钮内容 |
| --- | --- |
| 1261 px 起 | 状态图标、状态文案、版本号或下载百分比 |
| 1001–1260 px | 状态图标、版本号或下载百分比 |
| 1000 px 及以下 | 等高方形按钮，只显示状态图标；提示和无障碍名称仍保留完整状态 |

复用主题颜色和顶栏按钮。下载中使用进度环；未知下载大小时仅显示下载状态。点击或按 Enter 进入「设置 → 应用与更新」，定位软件更新项；若已有可用操作，则将键盘焦点移到该操作。下载和安装仍由设置页的按钮明确触发。

从仓库根目录运行（先在 `apps/desktop` 安装前端依赖）：

```sh
node apps/desktop/node_modules/vite/bin/vite.js --config docs/designs/2026-11-06-toolbar-update/v01/vite.config.mts
```

打开 [预览矩阵](http://127.0.0.1:5222/matrix.html)。可编辑预览源在本目录，使用同一提交中的生产组件和模拟数据；[浅色](previews/ready-zh-light.jpg)、[窄窗深色英文](previews/compact-en-dark.jpg)、[下载中](previews/progress-zh-light.jpg)、[跳转后的设置](previews/settings-zh-light.jpg)为浏览器实际渲染。

浏览器对照验证：880 × 560 下，更新就绪与无更新的内容区均为 456 px，图表均为 128.94 px。880 px 深色英文以及 1001、1261 px 英文在浏览器内检查了顶栏边界。键盘跳转到安装按钮，未知大小的下载不显示百分比，平台不支持时不显示按钮。未在原生应用内触发真实下载、重启或安装。
