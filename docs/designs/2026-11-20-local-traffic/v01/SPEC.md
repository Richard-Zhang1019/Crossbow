# 本地流量统计：读得懂的用量与去向

状态：已实现，待用户视觉/实机验收。关联 #567 / PR #581。日期 2026-11-20。

## 目标与方向

回答“这段时间用了多少，主要去了哪里”。沿用 Crossbow Frame Studio 的浅/深色变量、系统字体、共享 Button / SegmentedControl / NodeName。
知识库主方向②克制工具界面，辅方向①网格排版；参考库内 Vercel Guidelines（✅200）、coss ui（✅200 抽验）的层级与对齐方法，不引入新的设计系统。
tasteskill app draw：framed-sheet，seed 1912770209，保留 palette/type；仅重组统计内容，不更换已有窗口框架。

## 信息与交互

- 头部左侧标题与本地存储说明，右侧范围切换、刷新。
- 左侧区间总量、下载与上传；右侧每日堆叠柱图。只用数据的下载色和上传色，补字节刻度、日期和选中日详情；日期可鼠标/键盘点选，缺失日显示无数据，不当成真实零。
- 两列紧凑排行：名称/总量、上下行/本期占比、细占比条；占比分母是全部 daily 总量，不是第一名或 Top10 合计。小值不强加最小宽度。
- 小窗口压缩图表和留白，仅排行榜内部滚动。宽屏展示更多行；不把稀疏卡片拉满高度。
- 加载不冒充空态；不同范围不混用缓存，旧请求不能覆盖新范围；同范围刷新失败保留上次结果并提供重试。恢复后解除旧失败通知。
- 内核快照存在采样盲区；不将快照统计宣称为精确账单。

## 真实组件预览

源文件为 apps/desktop/src/pages/Stats/index.tsx、Stats.css；验证入口 scripts/dev/verify-stats.mjs。根目录安装依赖后运行 node scripts/dev/verify-stats.mjs。STATS_EVIDENCE 可设置截图目录。
source.zip 包含可编辑生产源文件、相关字典和脚本快照。preview.html 是当前真实 React DOM 的只读快照，交互以验证入口为准。

样本为脱敏 IPC 数据，各日上下行合计与域名/节点合计一致；不操作真实配置、系统代理或 TUN。基线 PR head 64244cf，合入 main 后实现。
