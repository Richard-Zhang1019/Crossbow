# Crossbow B 版界面规范

本次采用用户确认的 **Frame Studio** 布局与平衡冷灰深色主题，关联 #149。布局改动保留已有 IPC、通知队列、配置与 VPN 生命周期。

## 导航与功能

- 桌面一级导航：连接、节点、监测、配置、设置。
- 连接：真实内核状态、当前出口、独立系统代理 / TUN 开关、路由模式、实时流量和本次累计。
- 节点：左侧策略组，右侧地区 / 搜索 / 可用性 / 延迟筛选、单节点和整组测速；底部站点连通性。超时与未测速分开表达。 卡片依据筛选区与站点连通性之间的可用空间排两行或三行，高度 68–100px。分页器紧贴末行，单行结果保持紧凑（#410）。
- 监测：连接、日志、诊断；保留连接虚拟列表、进程聚合、日志跟随和诊断修复。
- 配置：来源、覆写链。来源使用列表与详情布局；URL / 文件导入统一入口，仍支持拖拽。覆写保留创建、启用、绑定、校验与应用。
- 设置：网络与内核、外观、日志、应用与更新。通知 / 托盘的旧页面标识保持兼容，更新入口定位到应用与更新。
- iOS：原生连接、配置、诊断三页。导入仍只支持本地 sing-box JSON，连接或切换中禁止替换配置，不增加尚未实现的订阅与测速入口。

## 交互与适配

桌面内容区左右留白随窗口收缩，最大 32px；导航与页头固定，页面外层不滚动。内容区高度最高 1000px，图表最高 300px；矮窗口压缩留白与辅助说明，设置行以双列均分剩余高度。连接表使用 ResizeObserver 测量可视高度，同一容器负责横纵滚动与吸顶表头；日志和编辑器也只在数据区滚动。节点、配置与覆写列表按可用高度分页，不再新增外层滚动条。顶栏两个按钮统一为 34px 高、相同底色与边框；输入焦点采用一条强调色边框与贴边弱色环，移除双层外描边。通知使用细边框与实体浮层色，不使用大面积阴影。设置下拉以 portal 定位并自动向上/向下展开，避免被固定容器裁切。按钮有 hover / 键盘焦点；弹窗支持 Escape、Tab 焦点循环和关闭后焦点恢复。通知继续使用统一 Notification，不引入私有 toast。

iOS 使用 NavigationStack、TabView、系统文件选择器与动态字体；主要操作触控区域至少 44pt。页面限制阅读宽度并可滚动，适应 iPhone、横屏和 iPad。底部栏保留当前 iOS 原生呈现。

## 最新桌面细节（#291）

- 设置行是语义分组，不是焦点控件；通知定位应滚动到设置行并聚焦行内实际按钮、输入或选择器。鼠标操作/异步禁用不能使整行出现焦点边框。设置滚动面向右外延 12px，内容对齐线保持不变。
- 日志级别使用共享 `Select` 的多选模式，默认 info / warning / error；触发器显示“日志级别 · 数量”，零选择时显示 0，菜单右侧显示勾选，选中项使用主题弱强调底色。保留单选兼容、键盘操作、portal 定位和减少动态效果支持。
- 日志复制按钮始终绝对定位并保持固定占位尺寸，仅改变透明度。实时行使用稳定身份；鼠标阅读或键盘聚焦复制操作时固定可见快照，后台仍接收日志，离开后按原跟随状态恢复；自动滚动在绘制前完成。
- 覆写页侧栏不再重复显示页标题，保留导航的可访问名称。
- 概览左侧按实际内容高度分配。先预留自然内容高度、两处 18px 段间距、操作到图表的 14px 间距和 120px 图表高度。剩余高度同时分给图表和间距，图表整体最多 200px，两处段间距各最多 72px，操作到图表最多 24px。各项达到上限后在底部留白，左侧整体最多 700px。连接路径图标统一 32px，路径排版按宽度适配，避免只调整高度时因内容密度切换导致图表跳变。长文案放不下时沿用整页滚动（#318）。
- 软件更新入口放在顶栏配置切换器左侧，和相邻按钮等高。空间充足时显示状态与版本或进度，随窗口收窄逐级简化为图标加数字、仅图标；点击定位到设置的「软件更新」。概览不为更新预留内容高度（#337）。
- 首次连接复用概览已有的状态行（#467 / #484）。无配置时在左侧标题下显示导入操作。内核下载或启动、定位接管开关、测试 GitHub 各自放在右侧「连接状态」对应行。测试期间只锁定测试动作，通过后同一行显示「GitHub 可达」，未通过时就地重试。该结果仅代表本次通过 Crossbow 代理端口的探测。

- 连接详情的标签、值和复制按钮按整行垂直居中；文本行高统一 20px，长进程路径自然换行，不截断可复制内容（#291 / PR #292 补充）。


## 正式品牌色（#301 / 主按钮配色，2026-11-05）

用户确认 B1 保留原始弧路/箭头，应用内 Logo 随主按钮的明暗色切换：浅色 **#293345**、深色 **#E7EAF2**。桌面 `--cb-brand` 与主题主按钮墨色一致，不跟随蓝紫强调色；官网按已解析主题选择对应 PNG，iOS 使用明暗 imageset。系统主题变化同样遵循这套规则。

macOS Dock、安装包、Windows/Linux 应用图标、iOS AppIcon、网站 favicon / Apple touch 均保留 **#F7F8FB 浅色底板 + #293345 标志**，不因所在桌面/浏览器主题变色。`app-icon-dark.svg` 仅为深底反白的矢量展示导出，不用于原生应用图标。黑/白托盘模板保留单色，交由系统着色。

唯一几何母版为 `design/logo/current/mark.svg`，使用 `scripts/generate-brand-icons.cjs` 生成正式资源；`scripts/verify-brand-icons.cjs` 校验明暗色、原始 B1 几何、生产位图/ICNS/ICO 的实际墨色、sRGB ICC、目录引用及 Dock 安全区。Dock 保留 9px 平移与 82% 缩放，避免重现图标视觉尺寸过大的问题。此决定替代 #297 的 A 岩蓝同色规范，旧设计稿保留追溯；最新实现档案为 `docs/designs/2026-11-05-button-logo/v02/`（PR #302）。
