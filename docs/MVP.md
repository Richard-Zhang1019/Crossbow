# Crossbow MVP 范围冻结（M0）

> 冻结日期：2026-10。范围之外的一切（包括看起来很小的）都进 M1/M1.5/M2，不在本周期实现。
> 平台：M0 仅 macOS（Tauri 2）；Windows 为 M1.5（CI 全程守护可编译）；iOS 为 M2。

## 目标

一个可以日常使用的 macOS 代理客户端：导入订阅 → 选节点 → 开系统代理 → 能上网 → 能看到连接与日志。

## In Scope（M0）

| 模块 | 内容 | 验收标准 |
|---|---|---|
| Profile | 导入（URL/粘贴/文件/拖拽/深链接 `crossbow://`）、更新、自动更新间隔、删除、设为当前 | 导入一个真实订阅后内核能以该配置启动 |
| 覆写 | merge（YAML patch）单个覆写，按 Profile 启停 | 开启覆写后配置渲染结果包含补丁内容 |
| 内核管理 | mihomo sidecar 生命周期（启动/停止/崩溃重启/版本显示），uds + secret 控制 | 崩溃后 5s 内自动恢复；退出后无残留进程 |
| 代理页 | 策略组/节点列表、单击选择、手动测速（并发）、固定节点 | 测速并发受控（≤ 并发 8），UI 不卡 |
| 首页 | 总开关、当前出口、实时上下行速率曲线（1s 刷新）、今日流量、连接数 | 关闭窗口后台常驻，速率持续准确 |
| 系统代理 | networksetup 全网络服务设置/还原；崩溃/强退兜底还原 | `kill -9` 后重启应用或托盘退出，系统代理状态正确 |
| 托盘 | 总开关、模式（直连/规则/全局）、当前配置、打开主窗口、退出 | 与主窗口状态双向同步 |
| 连接页 | 只读实时表：目标/规则/链路/上下行，过滤，2fps 节流 | 5000 连接下 UI 不卡 |
| 日志页 | 内核日志实时滚动 + 级别过滤，虚拟滚动 | 万行不卡，可复制 |
| 设置 | 混合端口、允许局域网、语言、主题、开机自启、内核版本查看 | 修改即时生效并持久化 |
| 基础体验 | 明暗主题、中英双语、单实例、升级前自动快照配置 | 全部走查通过 |

## Out of Scope（明确不做，防止蔓延）

- TUN 模式（M1 macOS NE / M1.5 Windows wintun）
- **Windows 平台支持（M1.5）**——但 M0 期间 CI 持续验证 Windows 可编译，禁止引入 Windows 破坏性代码
- JS 脚本覆写、覆写市场（M1）
- sing-box 引擎切换（M1）
- WebDAV / iCloud 同步（M1/M2）
- 轻量模式（M1）
- 诊断向导（M1）
- 规则命中统计（M3）
- **系统代理原设置保存/恢复**（S3 遗留打磨项：enable 前快照用户已有代理配置，disable 时还原——避免覆盖第三方客户端的设置）
- 中英双语（M0 后半补齐，当前仅中文）
- iOS 一切内容（M2）
- Linux（永久 out，除非重启决策）

## 里程碑切分（两周一个）

1. **S1**：仓库骨架 + crossbow-core（profile/渲染/快照，含单测）+ Tauri 壳启动
2. **S2**：订阅导入/更新 + 内核 sidecar 生命周期 + 能代理（curl 验证）
3. **S3**：代理页/首页 + 系统代理 + 托盘 + 兜底还原
4. **S4**：连接/日志页 + 设置 + 深链接/自启 + 打磨与真实订阅走查
