Features

把复杂留给内核，把简单交给你

每个特性都来自真实的日常使用反馈

订阅管理

URL / 粘贴 / 文件 / 拖拽 / 深链接导入，流量与到期一目了然；自动更新失败保留旧配置并指数退避重试。

系统代理守护

开启前快照原设置，退出/崩溃精确还原；内核异常自动降级恢复——告别「退出后断网」。

网络诊断向导

七项按依赖顺序自检：内核、控制器、配置、端口、系统代理指向、代理连通、DNS——失败项一键修复。

JS 覆写

用 function main(config) 改造订阅：过滤节点、改写规则。保存即校验，错误当场归因；沙箱执行无副作用。

轻量模式

关闭窗口 = 内核与代理保留、界面内存归零。重新打开自动接管，状态无缝恢复；托盘一键切换。

实时观测

速率曲线、按进程聚合的流量排行、单连接断开、分级日志——运行状态尽收眼底。

Get Started

三步上手

下载并安装

下载 dmg 拖入「应用程序」。首次打开右键 → 打开，或执行 xattr -dr com.apple.quarantine /Applications/Crossbow.app。

导入订阅

粘贴订阅链接回车，或直接把 .yaml 配置文件拖进窗口。设置自动更新间隔，流量与到期自动追踪。

一键开启

首页点亮开关：内核自动拉起、系统代理即时生效。选个节点，或让诊断向导帮你确认链路。

FAQ

常见问题

打开提示「无法验证」或「已损坏」？
应用未做 Developer ID 公证。首次打开右键 → 打开；或终端执行 xattr -dr com.apple.quarantine /Applications/Crossbow.app 后正常打开。
支持哪些协议？
内核为 mihomo，支持 Shadowsocks / VMess / VLESS / Trojan / Hysteria2 / TUIC / WireGuard 等全部 mihomo 所支持的协议，兼容 Clash 订阅与配置格式。
支持 TUN 模式吗？
暂缓评估中。当前通过系统代理覆盖浏览器与大部分应用；当你遇到「某应用流量不走代理」的真实需求时我们会重启 TUN 开发。
有 Windows / iOS 版本吗？
在路线图中：Windows 为 M1.5，iOS 为 M2（复用同一套核心逻辑）。目前 macOS 版本已可日常使用。
升级会丢配置吗？
不会。配置存储于 ~/Library/Application Support/com.crossbow.app/，每次保存前自动快照（保留 5 份），升级自动继承；坏覆写会触发安全模式兜底。
如何参与或反馈？
项目开源于 GitHub，Issue 与 PR 欢迎提交。日常使用中的每一条不便都是最高优先级的输入。
