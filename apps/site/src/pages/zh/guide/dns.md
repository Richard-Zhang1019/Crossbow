## 沿用订阅或自定义

打开 **设置 → 网络与内核 → DNS 解析**。默认「沿用订阅」保留配置行为；需要自定义时切换模式并填写解析上游，点击「保存并应用」。保存失败会保留已提交设置及待修改草稿，不代表新设置已生效。

| 字段 | 用途 |
| --- | --- |
| 代理业务上游 | 代理业务的默认解析；默认查询经 MATCH 策略出站 |
| 直连业务上游 | 直连出站所用的解析 |
| 节点引导上游 | 解析节点服务器域名；mihomo 留空时使用直连上游 |

## 两个内核的边界

**mihomo**：支持多个上游；自定义值优先于覆写/订阅的同名字段，同时保留 hosts、专用域名策略和 fallback，因此特定域名仍可能使用别的上游。

**sing-box**：代理和直连各支持一条上游，直连上游需用 IP 避免循环解析；不支持独立节点引导字段。原生 JSON 自定义 DNS 及无法转换的订阅 DNS/hosts 会明确拒绝应用。

IPv6仍受配置、运行时检测和 TUN 的 DNS/AAAA 策略约束。不要把一次保存理解为所有应用的 DNS 都会走同一解析器。

## 保存后验证

先确认通知没有应用或回滚失败，再在[DNS 解析路径诊断](/guide/dns-diagnostics)使用同一域名和记录类型对比系统与内核结果。
