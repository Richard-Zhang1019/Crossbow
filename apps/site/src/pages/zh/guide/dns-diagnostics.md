## 比较两条解析路径

打开 **监测 → 诊断 → DNS 解析路径**，填写域名并选择 `A` 或 `AAAA`，点击「检查解析」。分别显示系统解析和内核DNS接口结果、状态及观测耗时。

每次显式检查会把域名发送给系统/内核配置的解析服务；不自动后台查询。最近5条结果留在当前会话，可以复制或清除，不作为持久诊断记录上传。

## 如何判断下一步

| 结果 | 下一步 |
| --- | --- |
| 系统成功、内核失败 | 检查内核DNS上游、规则和服务 |
| 内核成功、系统失败 | 检查系统DNS及本地网络限制 |
| 两条均失败 | 先核对域名和网络，再排查DNS服务 |
| 两条均成功 | 继续检查代理连通性和站点本身，不能据此排除所有DNS问题 |
| 内核未运行/无法观测 | 启动内核后重试，不能当作内核解析失败 |

## 结果的边界

内核DNS接口不保证与每条业务连接的解析路径完全相同；hosts可能使系统不发DNS查询。上游、缓存命中及内核内部耗时未返回时显示未知，观测耗时包含控制器往返。

切换配置、内核、DNS模式或记录类型后重新检查，不沿用旧上下文的结论。[DNS设置](/guide/dns)与诊断查询是独立操作。
