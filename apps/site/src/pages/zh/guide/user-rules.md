## 为域名或 IP 指定策略

入口是 **配置 → 用户规则**。也可从 **监测 → 连接 → 连接详情 → 创建域名/IP 规则**带入目标，核对后保存。

| 条件 | 匹配范围 |
| --- | --- |
| DOMAIN | 精确域名 |
| DOMAIN-SUFFIX | 本域及子域 |
| IP-CIDR | 目标 IP 网段，不主动触发 DNS 解析 |

选择直连、拦截或可用策略目标。重复条件会被拒绝；编辑后保存并在连接详情验证实际命中。

## 优先级与失效目标

仅在规则模式生效，顺序为 **进程规则 → 用户规则（自上而下）→ 独立规则集 → 订阅规则**。可以上移、下移或停用条目。较宽的域名后缀或网段可能覆盖后面的规则，静态提示不等于真实内核命中。

订阅变化导致目标失效时，规则仍保留但不注入，不会悄悄降级为 DIRECT。先修正目标，再通过[连接观测](/guide/connections)检查。

当前配置包 v2 **不包含域名/IP 用户规则**，换机时不能假定它们已经随包迁移，详见[配置迁移](/guide/migration)。
