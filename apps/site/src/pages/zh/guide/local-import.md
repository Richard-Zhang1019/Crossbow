## 从哪里导入

在 **配置 → 配置来源 → 导入**，粘贴订阅 URL、Base64 订阅内容，或一条/多条节点分享链接。也可以从文件导入配置，或把配置文件拖入窗口。

1. 粘贴内容后等待「导入兼容性」检查。
2. 核对当前内核、节点数和不支持的协议/参数。远程 URL 的预检不会提前下载；真正导入时仍需获取和校验内容。
3. 确认导入。分享列表按整批处理，出现不支持的节点时不会只保留其中一部分。
4. 在右上角明确切到需要的配置，再前往 [节点选择](/guide/nodes)；导入成功不表示已经切换出口。

## 格式与兼容性

支持本地解析 SS、VMess、Trojan、VLESS、Hy2/Hysteria2 和 TUIC 分享链接及 Base64 内容，不发送给外部订阅转换服务。**支持一种格式不等于支持该格式的所有参数**：以导入预检结果和当前内核版本为准。

mihomo 与 sing-box 的原生格式及可转换子集不同。不能把原生 sing-box JSON 当作 mihomo 配置；不能转换的 DNS、hosts 等语义会明确拒绝，避免导入后悄悄改变路由行为。

v0.15.3 预检矩阵的关键边界：

| 分享能力 | mihomo | sing-box |
| --- | --- | --- |
| Hy2 | 支持已验证子集 | 有限支持 |
| TUIC | 支持已验证子集 | 当前转换不支持 |
| VLESS REALITY / vision | 支持已验证子集 | 当前转换不支持 |

该矩阵描述 Crossbow 当前导入/转换路径，不是对上游内核全部能力的判断。其他字段仍以本次预检为准。

## 导入失败时

检查完整列表中的协议、转义及参数，按提示修正后重试，不要只删除错误提示继续。URL 获取失败时先确认订阅源和本地网络；不要向他人公开带 token 的链接。

[浏览器深链接导入](/guide/deeplink)与[配置包迁移](/guide/migration)是不同入口。
